# Frontend/assets

ไฟล์ภาพนิ่งที่หน้าเว็บเรียกใช้ (เสิร์ฟผ่าน static mount ของ `main.py` เหมือนไฟล์
`.html` ปกติ — เข้าถึงได้ที่ `http://localhost:8000/assets/...`)

## adi-logo.svg — โลโก้บริษัทบนแถบเมนู

แถบบนของทั้ง 3 หน้า (`index.html` / `edit.html` / `export.html`) มีช่องสำหรับ
โลโก้อยู่หน้าคำว่า "TM-X Control System" แล้ว โดยอ้างถึงไฟล์นี้:

```html
<img class="topbar-logo" src="assets/adi-logo.svg" alt="Analog Devices" />
```

**ยังไม่มีไฟล์นี้ในโปรเจกต์ — ต้องเอามาวางเอง**

โลโก้ Analog Devices เป็นเครื่องหมายการค้าจดทะเบียนของบริษัท จึงควรใช้ไฟล์
ต้นฉบับจากฝ่ายที่ดูแลแบรนด์โดยตรง ไม่ใช่วาดเลียนแบบขึ้นมาใหม่ เพราะ

1. เป็นเครื่องหมายการค้า การวาดใหม่เองอาจผิดข้อกำหนดการใช้งานแบรนด์ของบริษัท
2. ไฟล์ที่วาดเลียนแบบจะได้สัดส่วน/เฉดสีน้ำเงินไม่ตรงกับของจริง ซึ่งฝ่ายแบรนด์
   มักมีค่าสีที่กำหนดไว้ชัดเจน

### วิธีเอาไฟล์มา

ขอไฟล์โลโก้ทางการจากฝ่าย Communications / Marketing ของ ADI หรือดาวน์โหลดจาก
brand portal ภายในบริษัท แล้ววางไว้ที่โฟลเดอร์นี้ในชื่อ `adi-logo.svg`

- แนะนำ `.svg` (คมทุกความละเอียด ไฟล์เล็ก) ถ้าได้มาเป็น `.png` ให้ใช้ตัวที่
  ความสูงอย่างน้อย 60px แล้วเปลี่ยนนามสกุลใน `src` ของทั้ง 3 ไฟล์ให้ตรงกัน
- ควรใช้แบบ "โลโก้ + ตัวอักษร" แนวนอน (แบบเดียวกับที่เห็นบนหัวจดหมายบริษัท)
  เพราะแถบเมนูสูงแค่ 52px พื้นที่แนวตั้งจำกัด

### ถ้ายังไม่ใส่ไฟล์

หน้าเว็บจะยังทำงานปกติ — `onerror` ในแท็ก `<img>` จะซ่อนตัวเองอัตโนมัติ
ไม่ขึ้นไอคอนรูปแตกและแถบเมนูไม่เพี้ยน

### ปรับขนาด

แก้ที่ `.topbar-logo` ใน `<style>` ของแต่ละไฟล์ (ค่าเริ่มต้น `height: 26px`)
