# Actions · Web Application — คำบรรยายแต่ละรูป

**หัวเรื่องรอง (ใต้คำว่า Web Application)**
> One screen for the whole job — set up the run, watch it, and keep the record

---

## แถวซ้าย — ระหว่างวัด และหลังวัด

### รูปที่ 1 · Dashboard
**One screen while measuring**
The value, the verdict, the image the camera took, and where the run is in the queue

### รูปที่ 2 · Measurements table
**Every reading is kept, not written down**
Searchable by ALPL and by date, with the image stored beside each row

---

## แถวขวา — ก่อนกด Start

### รูปที่ 3 · Part Entry (ว่าง)
**Nothing starts until the parts are entered**
The queue the operator builds here is what the machine will measure, in that order

### รูปที่ 4 · IPM
**IPM asks only what it needs**
ALPL, package size and operator — an ALPL that has never been measured is registered on the spot

### รูปที่ 5 · New / Rework
**New and Rework ask for the full part record**
New blocks an ALPL that already exists · Rework blocks one that does not
