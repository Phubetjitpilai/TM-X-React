# หน้า 41-43 · Web Application — ชื่อ Card + คำอธิบายใต้รูป

---

## หน้า 41 — Setting up the run
*ชิปข้างคำว่า Actions:  `Web Application · Before the run`*

| ชื่อ Card | คำอธิบายใต้รูป |
|---|---|
| **Part Entry** | Nothing starts until the parts are entered |
| **IPM** | ALPL, package size and operator — that is all IPM needs |
| **New / Rework** | The full part record · New blocks an ALPL that exists, Rework blocks one that does not |

---

## หน้า 42 — Running it
*ชิป:  `Web Application · During the run`*

| ชื่อ Card | คำอธิบายใต้รูป |
|---|---|
| **Session Control** | Start, stop, and the state of the machine at a glance |
| **Live Telemetry** | The value and the verdict as each part is measured |
| **Camera Preview** | The image the camera took, kept with the reading |
| **Queue & Progress** | Which part is being measured, and how many are left |

---

## หน้า 43 — Keeping the record
*ชิป:  `Web Application · After the run`*

| ชื่อ Card | คำอธิบายใต้รูป |
|---|---|
| **Measurements** | Every reading is kept, not written down |
| **Edit** | Fix what was typed wrong — the measured values stay locked |
| **Export** | CSV, Excel or PDF — filtered before it leaves |

---

## ถ้าที่ว่างน้อย ใช้แบบสั้น

| Card | สั้น |
|---|---|
| Part Entry | Build the queue before Start |

| New / Rework | The full part record |

| Camera Preview | The image, kept with the reading |
